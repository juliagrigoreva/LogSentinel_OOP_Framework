# LogSentinel — ООП-фреймворк для анализа логов

Учебный проект на Python для автоматического анализа серверных логов в формате JSON. 
Реализована единая система классов с наследованием: один базовый класс (отвечает за чтение файла), 4 дочерних класса решают конкретные задачи по анализу данных.

——————————

## Из чего состоит фреймворк

Все парсеры наследуются от родительского класса BaseLogParser, который читает файл построчно через генераторы (yield).

1. NightCrashParser — ищет ошибки в ночной период (с 00:00 до 04:00) с помощью itertools.filterfalse и считает их через Counter.

2. PeakHourParser — анализирует логи за 24 часа, группирует ошибки по часам через defaultdict и определяет самый пиковый час в сутках.

3. SecurityLogParser — ищет попытки взлома с помощью регулярных выражений (re) и собирает список уникальных IP-адресов в set.

4. EmailLogParser — вытаскивает email-адреса пользователей и автоматически раскладывает их по статусам (SUCCESS / ERROR) через defaultdict.

——————————

## Используемые технологии и модули

• Язык: Python 3.8+

• ООП (Объектно-Ориентированное Программирование).

• Оптимизация памяти: Потоковое построчное чтение через yield.

• Модули стандартной библиотеки:

• json — десериализация логов.

• re — поиск IP-адресов и email по шаблонам (Regex).

• datetime — парсинг и форматирование дат/времени.

• collections (Counter для подсчета ошибок, defaultdict для группировки).

• itertools (filterfalse).
